# Color grading w Photoshopie: chłodne cienie, ciepłe światła

Zadanie z grafiki (PJATK). Korekcja kolorów dwóch zdjęć (wilk i plaża): chłodne cienie, ciepłe światła i dwa nowe obiekty dodane do każdego zdjęcia.

**Typ:** zadanie indywidualne
**Narzędzia:** Adobe Photoshop 2026, skrypt ExtendScript (JSX) do automatyzacji warstw

## Technika
- warstwy dopasowania: Jasność/Kontrast, Barwa/Nasycenie, Krzywe
- dwie warstwy Solid Color z maskami: Soft Light (chłodne cienie) i Color Dodge (ciepłe światła)
- maski dopracowane ręcznie miękkim pędzlem (krycie 20%)
- dodane obiekty: kruki (wilk), żaglówka i kontenerowiec (plaża)
